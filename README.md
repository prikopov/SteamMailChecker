# Steam Mail Checker

Локальный чекер для Windows x64. Собирает письма Steam из ваших почтовых ящиков и показывает их в одном окне. Python для запуска EXE не нужен.

[Скачать EXE для Windows x64](https://github.com/prikopov/SteamMailChecker/releases/latest)

> [!IMPORTANT]
> **Дисклеймер.** Используйте программу только для своих почтовых ящиков или с явного разрешения владельца. Локальные TXT могут содержать коды Steam Guard, ссылки восстановления и другие личные данные. Не публикуйте архив писем, настройки, токены и пароли. Проект не связан с Valve или Steam.

## Запуск

1. Распакуйте ZIP и откройте **SteamMailChecker.exe**.
2. Нажмите **Добавить ящик**, введите адрес или логин и пароль приложения. Для распространённых доменов программа подставляет IMAP-сервер. Для другого сервиса укажите его IMAP-хост и TLS-порт (обычно 993). Если сервис требует OAuth, можно указать действующий IMAP-токен в режиме **XOAUTH2**. Программа сама токен не получает и не продлевает.
3. Нажмите **Сохранить и запустить**. Повторите для остальных ящиков. **Запустить все** включает проверку всех настроенных ящиков. **Проверить сейчас** запускает очередное обновление.
4. Щёлкните письмо для просмотра. Чтобы поднять старые письма наверх, нажмите заголовок **Дата письма**. Поиск сверху фильтрует по теме, ящику и отправителю. Переключатель **Только выбранный ящик** ограничивает список.
5. Кнопка **Папка TXT** открывает локальный архив. Для каждого ящика своя папка, для каждого письма свой UTF-8 TXT с датой, темой, отправителем и текстом.

## Подключение почты

- **Gmail** — imap.gmail.com. Если для аккаунта доступен пароль приложения, используйте его. [Справка Gmail](https://support.google.com/mail/answer/7126229)
- **Яндекс Почта** — imap.yandex.ru. Разрешите IMAP в настройках почты и создайте пароль приложения. [Справка Яндекса](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others)
- **Почта Mail** — imap.mail.ru. Создайте пароль для внешнего приложения. [Справка Mail](https://help.mail.ru/mail/faq/password/)
- **Outlook.com / Hotmail** — outlook.office365.com. Включите IMAP. Для IMAP нужен OAuth2. Вставьте выданный для IMAP токен и включите XOAUTH2. [Справка Microsoft](https://support.microsoft.com/en-au/outlook/pop-imap-and-smtp-settings-for-outlook-com)

## Как работает

- При запуске сканируются доступные папки, которые показывает IMAP. Затем проверяются новые письма примерно каждые 30 секунд, пока программа открыта. Если сервер не показывает архив, спам или корзину через IMAP, чекер не может обойти их.
- Поиск идёт по адресу в поле From. Чекер принимает домены steampowered.com и steamcommunity.com и их поддомены. Это фильтр отправителя, а не криптографическое подтверждение подлинности письма. [Адреса отправителей Steam Guard](https://help.steampowered.com/en/faqs/view/06b0-26e6-2cf8-254c)
- Папки открываются в режиме чтения. Письма не помечаются прочитанными, не перемещаются и не удаляются. Вложения не выгружаются. HTML преобразуется в текст, внешние картинки не загружаются.
- Папки разных ящиков разделены. Копии одного письма в разных папках одного ящика экспортируются один раз. Локальный архив остаётся после закрытия программы и после удаления ящика из списка.
- Данные хранятся в %LOCALAPPDATA%\SteamMailChecker. TXT могут содержать приватные письма, коды и ссылки Steam. Без галочки **Запомнить в моём профиле Windows** пароль или токен хранится только до закрытия чекера. С галочкой учётные данные шифруются Windows DPAPI для текущего пользователя.
- Самое старое найденное письмо помогает определить исходный ящик, но не доказывает это, если письма о регистрации не сохранились.

## Сборка

Исходники в папке sources. Для сборки на Windows установите Python 3.14, pywin32 и PyInstaller. Из папки sources запустите: python -m PyInstaller --windowed --onefile --name SteamMailChecker app.py
